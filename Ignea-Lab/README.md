# Ignea Lab

Opentrons protocols developed for the Ignea Lab @ McGill University, split by robot platform:

* [`Flex/`](Flex/README.md) — protocols for the Opentrons Flex (PCR, miniprep, calibration utilities)
* [`OT-2/`](OT-2/README.md) — protocols for the Opentrons OT-2 (PCR, miniprep, cloning workflows)

See each folder's README for a full breakdown of available protocols.
